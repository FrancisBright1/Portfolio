## Quick Deploy to Vercel (Recommended)

### Option 1: One-Click (Fastest)
1. Push this folder to a new GitHub repository
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the repository → Vercel auto-detects Next.js
4. Deploy (takes ~30 seconds)

### Option 2: Local → Vercel CLI
```bash
# 1. Install dependencies
npm install

# 2. Build locally to verify
npm run build

# 3. Install Vercel CLI (if not already)
npm i -g vercel

# 4. Deploy
vercel --prod
```

Your site will be live at `https://your-project.vercel.app` instantly.
