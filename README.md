# Francis Chibuike Bright — Portfolio

Personal site for a Data Analyst focused on business and product analytics.

**Stack:** Next.js (App Router) · TypeScript · Tailwind CSS · Framer Motion

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm run build
npm start
```

## Deploy

Push this folder to GitHub and import the repository in Vercel. The live site currently points at the `FrancisBright1/Portfolio` repo.

## Content rules used in this version

- Positioned as a Data Analyst, not as a data scientist, data engineer or product manager.
- Skill percentages removed.
- Unverified testimonials removed.
- Project write-ups only use findings that can be defended from the public repos or the CV.
- Missing dashboard or GitHub links are stated as missing instead of pointing to `#`.
